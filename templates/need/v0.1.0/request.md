# DA-TARGET-0001: bounded capability title

This is a case-derived demand packet. It is not a protocol proposal, a finding
of wrongdoing, or evidence that the target repository has accepted a change.

## Blocked operation

Describe the smallest operation that cannot be reproduced against the exact
target revision in `manifest.json`.

## Evidence and reproducer

Explain what the fixture preserves, then give the same literal command recorded
in the manifest. Keep the fixture sufficient to reproduce the need and omit the
rest of the investigation dossier.

## Capability boundary

Ask for a capability, not an implementation. Name the current workaround and a
counterexample that would route the need back to an application adapter or an
already-existing target contract.

## Non-claims

Repeat the interpretation boundaries most likely to be lost when this packet is
read without the source case.
