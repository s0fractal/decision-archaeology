# Candidate investigations

This directory is a quarantine boundary, not a gallery of published cases.
A candidate may contain a source-sufficiency audit, search log, and admission
gate, but it must not be described as a completed dossier or placed under
`examples/` until its core claims can be bound to attributable evidence.

Admission requires:

1. a bounded retrospective question;
2. exact identities for the material contracts, decisions, and actors;
3. a source inventory that distinguishes public, restricted, reported-only,
   missing, and disproven links;
4. first-class counterclaims and alternative explanations;
5. a lawful acquisition and publication plan;
6. at least one useful deterministic check over retained inputs.

Failure to pass the gate is a result. It prevents source scarcity from being
converted into false certainty by a polished graph.
